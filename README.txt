TENSOR MATH E-LIBRARY (5-FILE SETUP)
====================================

Files included:
1. index.html  - Main Rokomari-style grid & PDF popup modal
2. style.css   - Responsive styling & Full Screen layout
3. books.js    - Verified book titles, writers, editions & Google Drive file IDs (9 books)
4. app.js      - Live cover thumbnails, search, popup reader & full screen toggle
5. README.txt  - Setup guide

How to add a new book later:
- Open books.js and add a new object to BOOKS_DATA with id, title, writer, edition, and fileId.
